# PokerProvide PHP SDK

Official PHP 8+ SDK for the **PokerProvide** Poker-as-a-Service B2B API.
Version 1.1.0.

## Install

```
composer require pokerprovide/sdk
```

Or drop these files into your project directly (no build step required for the core client).

## Quick start

```
See example.php in this package.
```

Your sandbox public key (`pk_sbx_YOUR_PUBLIC_KEY`) is pre-filled in the example. **Never commit your secret key** —
load it from an environment variable (`PP_SECRET_KEY`).

## What's included

- `sign()` — HMAC-SHA256 body signing (sets `X-Operator-Signature`).
- `createSession` — create a player session / launch token for the white-label client.
- `walletBalance` / `walletDebit` / `walletCredit` — seamless wallet calls (idempotent on `transaction_id`).
- `tournaments.*` — Tournament Factory API: `list`, `get`, `structure`, `payouts`, `players`, `results`, `register` (idempotent buy-in) and `unregister`.
- `verifyWebhook` — timing-safe verification of inbound webhook signatures (`X-PokerProvide-Signature`).

## Authentication

Every authenticated request is signed: `X-Operator-Signature = HMAC_SHA256(secret_key, raw_json_body)`,
sent alongside `X-Operator-Key: <public_key>`. The SDK handles this for you.

## Base URLs

- Production: `https://api.pokerprovide.com`
- Sandbox: pass your sandbox base URL to the constructor if different.
